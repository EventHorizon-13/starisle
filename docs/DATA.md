# 数据初始化与离线部署

`data-manifest.json` 固定来源 URL、字节数和 SHA256。基础模式下载 DE440 和 Hipparcos；完整模式额外下载火星、木星、土星、天王星、海王星、冥王星的自然卫星星历，以及 AT-HYG v3.2 10 等子集和 OpenNGC v20260501。

AT-HYG 使用上游 GitHub 的冻结历史版本；当前上游开发已迁到 Codeberg。固定数据版本旨在复现发行版，不自动跟随最新星表。

生成 `catalog.sqlite3`、`stars-m10.npy` 和 `deep-sky.json` 的脚本随镜像分发。源目录压缩包缓存在 `data/downloads/`；生成的深空目录由应用优先从 data 加载，基础版回退到随镜像提供的目录。

## 校验不通过

不要关闭校验。先核对网络下载是否是错误页，以及上游文件是否修订。维护者验证新数据后可更新清单并发布新版。`--replace` 仅允许用符合清单的下载替换现有文件，不能接受不同校验值。

目录生成在临时目录完成后逐文件替换；不是三个文件的跨文件系统事务，因此必须停止应用实例再更新目录。初始化进程间使用文件锁。

## 无网络环境

在可联网的设备初始化完整 data 后，连同应用镜像迁入离线服务器，设置 `OFFLINE=true`。复制运行中的 SQLite 需使用一致性快照；不需要分发个人运行历史、访问日志或 `.env`。

地球定向表默认取 Skyfield 随包内容；可联网且需要更新时显式设置 `IERS_UPDATE=true`。实际天文日期精度还取决于所用星历与时标数据。

## 数据更新与许可证

目录派生文件按 CC BY-SA 4.0 保留署名；初始化会写入 `data/DATA-LICENSES.md`。JPL、CDS 和运行时 CelesTrak 数据保留来源条款，不统一声明成 MIT。

卫星轨道每来源至少缓存 6 小时；429 和 5xx 会停止当前刷新轮次，留待下一轮，不对上游连续重试。
